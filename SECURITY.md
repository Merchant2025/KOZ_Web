# Безопасность

Не публикуйте сведения об уязвимостях в открытых Issues. Передайте описание владельцу репозитория приватным способом.

До production-публикации CSP и другие security headers должны настраиваться на веб-сервере. Формы разрешается добавлять только вместе с серверной валидацией, защитой от CSRF и документированным порядком обработки персональных данных.
