# KOZ Web

Статический прототип нового интерфейса сайта ООО «Камышинский опытный завод».

## Статус

Это не действующий официальный сайт. Репозиторий намеренно не содержит неподтверждённых телефонов, показателей, проектов, партнёров, характеристик продукции и имитации отправки заявок. До согласования содержимого поисковая индексация запрещена.

## Структура

- `index.html` — семантическая разметка;
- `css/styles.css` — адаптивные стили без внешнего CSS-фреймворка;
- `js/app.js` — доступное мобильное меню и текущий год;
- `_headers` — HTTP-заголовки безопасности для Netlify;
- `tests/site.test.js` — проверки статуса прототипа и отсутствия временных данных;
- `.github/workflows/web-ci.yml` — автоматическая проверка JavaScript и тестов.

## Проверка

```bash
npm install
npm run check
```

## Публикация

Проект является статическим сайтом без этапа сборки. Целевая платформа публикации — **Netlify**: в настройках сайта каталогом публикации должен быть корень репозитория, а команда сборки не требуется. Файл `_headers` в корне — поддерживаемая Netlify конфигурация HTTP-заголовков; при публикации он передаёт полную CSP, включая `frame-ancestors 'none'`, а также `X-Content-Type-Options`, `Referrer-Policy` и HSTS.

HSTS настроен на один год без `includeSubDomains` и `preload`, поскольку готовность всех поддоменов не подтверждена. Заголовок разрешается выпускать только для production-домена с постоянно включённым HTTPS. После развёртывания заголовки необходимо проверить по публичному HTTPS-URL, например:

```bash
curl -sS -D - -o /dev/null https://<production-domain>/
```

Meta-CSP из `index.html` удалён: Netlify позволяет передать полную политику HTTP-заголовком, который, в отличие от meta-CSP, поддерживает директиву `frame-ancestors`.

## Перед production-публикацией

Необходимо согласовать материалы с предприятием, перенести каталог и контакты из утверждённого источника, подключить реальный backend форм, подготовить политику обработки персональных данных, привязать production-домен с HTTPS и снять `noindex` только после финальной проверки. Если площадка публикации будет изменена, эквивалентная серверная конфигурация заголовков обязательна: одного meta-тега CSP недостаточно.

Исходный код и материалы предприятия не предоставляются по открытой лицензии.
